# 后台这次更新：日常操作上的变化

给李、陈看。这次更新的目的只有一个：**做过的事要能查到结果和证据，询盘要能查到来路，钱要能查到去向。**
下面只列「你明天操作时会不一样」的地方，按遇到的频率排。

## 一、勾任务完成时，会弹出一个框

以前点一下就算完成。现在点完会弹框，填了才算：

| 要填什么 | 谁必须填 |
|---|---|
| **完成结果**（至少 4 个字）：上线了什么 / 改成了什么 / 数据到了多少 | 所有任务 |
| **证据**：链接（http/https 开头）或截图，有一样就行 | 重要任务 |
| 具体动作、实际用时 | 可选，建议填 |

- 点「取消」等于没点过，任务还是未完成。
- 任务的日期要用日期框选，别手敲别的写法；开始日不能晚于截止日。
- 完成之后还能改结果、补证据，但**不能把结果清空，也不能把最后一张证据图删掉**。

**什么算「重要任务」——系统按下面的规则判，不是自己选：**

- 有人把它的「重要度」选成了重要任务（谁都能选，**只有经理 / 老板能取消**）
- 挂了花费（付费外链、其它支出关联到了这条任务）
- 是从整改清单排下来的
- 跨天的任务（**把跨天任务改成单日也还是算**，改日期躲不掉证据）
- 公司派发的大任务

## 二、建任务时多了几项可填

- **产品 / 项目**、**预估工时**。
- **关联对象**：这条任务动的是哪个页面、哪个广告系列、哪个关键词（从已同步的数据里选）。

关联了，任务完成后卡片上会多一个「数据变化」按钮，能看到完成前后 7 / 14 / 28 天的点击、排名、花费、转化。
**没关联，就没法说这条任务带来了什么变化**，周度审核里会标出「无法验证数据变化」。

### 任务建好之后再改，会留记录

改任务的内容、负责人、起止日、预估工时，或者完成之后再改结果和证据，系统都会记下是谁、什么时候、从什么改成什么。
任务卡上会出现「改 N」，点开能看；周度审核里会标出「截止日被往后改过」「完成之后又改了内容」。
正常调整没有问题，只是别人能看到。

## 三、询盘的渠道和等级：你录的是「待确认」

- 你录入的渠道、等级先显示为**待确认**，经理或老板确认后才定稿。
- **确认之后，你改不了这条询盘的渠道、等级和日期，也删不掉它**，会提示「请找经理或老板」。确认前可以随便改。
- 每次改动都会留下记录：谁、什么时候、从什么改成什么。行上显示「改 N」，点开能看。
- 等级不能清空；日期必须是真实日期。

## 四、询盘来源

- 录询盘时可以填**来源词**、**广告系列**（只能从已同步的系列里选）、**落地页**（完整网址）。
- 系统会拿你填的来源词，去和 Ads、Search Console 的真实点击数据对一下，在旁边标「有据 / 两边都有 / 对不上 / 存疑」。
  这只是提示，方便复核，不会改你填的内容，也不计分。
- 独立站表单接入后（还没接）：表单带回来的线索会出现在「表单线索」里，核对后点「转为询盘」并评级，
  来源自动带入且**不能手改**。垃圾线索点「忽略」，**要写原因**。

## 五、测试登记：归档前要写结论

没写结论不能归档。放弃的测试也要写一句为什么放弃。

## 六、新页面：投入台账

「投入台账」记每个月的钱花在哪：

- **外链**：付费和免费的都逐条登记（所在页面、指向我们的哪个页面、锚文本、属性、费用、卖家）。花了钱的必须填币种和日期。
- **其它支出**：工具订阅、内容外包等。外链的钱只记在外链那边，别两边都记。
- 每条外链有「自动核查」：系统去那个页面上找一次指向我们的链接，并告诉你页面上实际是 dofollow 还是 nofollow。
  「没找到」「页面没取到」**不等于失效**（对方可能拦了自动访问），它不会替你改状态。
- 系统每天凌晨还会自动把一周没查过的外链查一遍。行上出现加粗的「**上次还在，这次没找到**」时，请去那个页面看一眼：多半是对方把链接撤了。

## 六点五、数据看板多了一个诊断：点击率偏低

「数据看板 → SEO → 点击率偏低」列出这样的词：已经排在首页、曝光也不少，但点进来的人明显比我们站里同样排位的词少。
这类词排名不用再冲，改标题和描述就可能多拿点击。每条可以让 AI 给改写建议，也可以直接「采纳」进整改清单。
注意它比的是**我们自己站里**同位次的词，不是行业水平。

## 七、删除

- 任务、外链、支出删掉后，会在**周度审核**里单独列出来（当天建当天删的不列），带删除人。
- 询盘归档同理，会列出归档人。
- 「彻底删除」只有老板能做。

## 八、周度审核

经理 / 老板每周会在「周度审核」页按人看：完成了哪些任务、结果和证据、完成前后的数据变化、工时、逾期和没推进的任务，
以及询盘质量、花费、KPI。上面一到七条填进去的东西，最后都汇总到这一页。

所以平时最省事的做法就是：**建任务时把关联对象选上，完成时把结果写实、把证据贴上。**

---

有哪一步被拦住但你觉得不该拦，把页面上的提示原话发出来，方便排查。
